VALORE DEAL ENGINE — how to use

1. Double-click index.html (keep calc.js in the same folder). It opens in your browser.
2. Tabs:
   • Dashboard — your KPIs vs the £10–15k/mo and £1m targets (counts deals marked "live").
   • Analyser — pick R2SH single-let, R2SH HMO/TA, or BRR. Numbers update as you type.
     Same formulas as the financial model. Hit "Save deal".
   • Property Lookup — type any UK postcode for live area/demand data (free, no key).
   • Sourcing — set your criteria; saved deals are auto-scored out of 100.
   • Saved Deals — ranked pipeline. "Pack/LOI" makes a branded, printable deal pack +
     letter of intent (print → Save as PDF). Export/Import backs up your data as JSON.
   • Settings — targets, default assumptions, optional API keys for the cloud build.

Your data is stored privately in this browser (localStorage). Use Export to back it up
or move it to another computer.

No internet is needed except the live postcode lookup. Nothing is sent anywhere.
