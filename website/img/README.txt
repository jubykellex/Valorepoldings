VALORE WEBSITE — IMAGERY

The site currently uses bespoke SVG "plates" (premium duotone illustrations) as
placeholders. To swap in real photography, you have two easy options:

OPTION A — keep the same filenames (no code changes)
  Replace these files with real photos, keeping the names:
    plate-terrace.svg   → a row of homes / street at dusk        (wide, ~16:10)
    plate-interior.svg  → a clean, warm interior / living room    (~4:3)
    plate-skyline.svg   → a city skyline or new-build / growth     (~4:3)
    plate-portrait.svg  → your founder portrait                    (~4:5, vertical)
  You can use .jpg/.png instead of .svg — if so, also update the src="img/..."
  references in the .html files (find "plate-" and change the extension).

OPTION B — ask Claude to wire them
  Drop your photos in this folder and tell Claude the filenames; it will update
  every <img> across the pages for you.

RECOMMENDED SHOTS (for a premium, Coutts-like feel)
  • Warm, natural light. Avoid stocky/staged corporate images.
  • Real UK homes (terraces, interiors), tidy and well-kept.
  • One genuine founder portrait — the single biggest trust signal on the site.
  • Consistent colour temperature so the set feels like one brand.

Licensing: if using stock, confirm a commercial licence (e.g. Unsplash/Pexels are
free for commercial use; always check the specific image's terms).
